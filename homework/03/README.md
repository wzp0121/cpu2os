# Gemini Rogue - Web Edition

Gemini Rogue 是一款基於 Python **非同步 (asyncio) 架構** 打造的 **網頁版** Rogue-like 冒險遊戲。本專案將傳統的地下城探索與現代 **LLM (Large Language Model) 技術**相結合，利用 Google Gemini API 即時生成怪物的對話與隨機寶箱事件，為玩家帶來每次冒險都獨一無二的動態體驗。

---

## 🎮 專案特色

1. **網頁介面 (Web UI)**：採用 Flask + HTML/CSS/JavaScript 構建現代化網頁介面，支援鍵盤操控與虛擬搖桿，不再受限於終端機畫面閃爍問題。
2. **非同步架構 (asyncio)**：遊戲引擎與外部 AI 服務（如 Gemini API）的對話皆採用非同步非阻塞設計，確保網路連線不影響玩家操作。
3. **AI 動態生成 (AI-Driven)**：引入 Gemini 2.0 Flash 模型，當玩家遭遇怪物或開啟神秘寶箱時，AI 會依據目前的戰鬥與環境情境動態生成客製化的挑釁台詞與情境對話。
4. **雙顯示模式**：支援經典 ASCII 與 Emoji 圖形兩種地圖渲染模式，可隨時切換。

## ⚙️ 核心機制與狀態機設計

遊戲內部邏輯圍繞著一個有限狀態機 (Finite State Machine, FSM) 運作，主要包含以下四種狀態：

```
               ┌───────────────┐
               │    EXPLORE    │◄──────────────┐
               └──────┬─────┬──┘               │
                      │     │                  │
         碰撞怪物     │     │   碰撞寶箱       │ 戰鬥獲勝 / 事件結束
         ┌────────────┘     └────────────┐     │
         ▼                               ▼     │
   ┌───────────┐                   ┌───────────┴┐
   │  BATTLE   │                   │   EVENT    │
   └─────┬─────┘                   └────────────┘
         │ 玩家 HP <= 0
         ▼
   ┌───────────┐
   │ GAMEOVER  │
   └───────────┘
```

1. **EXPLORE (探索模式)**：
   * 玩家（`P` / 🧙）使用 `W/A/S/D` 或方向鍵在由隨機漫步演算法（Random Walk）生成的隨機地牢中探索。
   * 可以探索地表、尋找隱藏的寶箱（`B` / 📦）或是尋找通往下一層的樓梯（`>` / 🪜）。
2. **BATTLE (戰鬥模式)**：
   * 當玩家與怪物（`M` / 👹）碰撞時觸發。畫面上會即時顯示由 AI 根據怪物種類與當前血量動態生成的挑釁或求饒對話。
   * 玩家可選擇攻擊、防禦或使用藥水。戰鬥中採用回合制交互，玩家行動後怪物將會發動反擊。
3. **EVENT (事件模式)**：
   * 當玩家觸發寶箱時，AI 將生成一段地牢神秘祭壇或寶箱的情境描述與雙重選擇。玩家的抉擇會帶來不同的能力提升或資源獲取。
4. **GAMEOVER (遊戲結束)**：
   * 玩家生命值歸零時觸發，顯示結束畫面，可點擊重新開始。

## ⚔️ 裝備與戰鬥系統

本遊戲針對 Rogue-like 核心的數值計算與裝備系統進行了深度擴充與優化，確保策略性與耐玩度：

### 1. 裝備資料結構
遊戲中定義了 `Equipment` 類別，分為**武器 (Weapon)**與**防具 (Armor)**兩大類別：
* **武器**提供 `atk_bonus`（攻擊加成）。
* **防具**提供 `def_bonus`（防禦減傷加成）。

### 2. 核心戰鬥與傷害公式
* **玩家總攻擊力**：$\text{基礎攻擊力 (p.atk)} + \text{武器加成 (atk\_bonus)}$。
* **物理減傷公式**：
  * **怪物承受傷害**：$\max(0, \text{玩家總攻擊} - \text{怪物防禦})$
  * **玩家承受傷害**：$\max(0, \text{怪物攻擊} - \text{防具減傷加成})$
  * 所有傷害計算皆經過嚴格封裝，確保不會出現負數傷害的情況。

### 3. 防禦機制 (`DEFEND`)
在戰鬥回合中，玩家可以選擇 **2. 防禦**：
* 啟動後，玩家進入 `is_defending = True` 狀態。
* 該回合怪物反擊造成的**最終承受傷害將會減半**（採用整數除法，`actual_damage // 2`）。
* 當回合怪物反擊結束後，防禦標記將會**自動重置**為 `False`。

### 4. 裝備整合至隨機事件
當玩家打開寶箱並選擇大膽嘗試時，有一定機率從裝備庫中隨機獲得一件新武器或防具，並**自動裝備**：
* **武器庫**：`鏽鐵劍 (ATK+3)`、`精鋼劍 (ATK+7)`、`神火大劍 (ATK+15)`、`黑曜石雙刃 (ATK+25)`
* **防具庫**：`粗糙布衣 (DEF+2)`、`輕盈皮甲 (DEF+5)`、`精鋼鎖子甲 (DEF+10)`、`星辰守護鎧 (DEF+20)`

## 🚀 快速擴充指南

如果您希望在此遊戲引擎基礎上進行二次開發或客製化，可以參考以下指引：

### 1. 抽換 AI 服務或提示詞
* **檔案位置**：`ai_service.py`
* 您可以修改 `get_monster_dialogue` 與 `get_chest_event` 函式。
* 如果想更換為其他模型（例如 OpenAI GPT 或是 Anthropic Claude），只需替換客戶端初始化代碼，並將呼叫封裝在 `asyncio.to_thread` 中以避免同步阻塞。

### 2. 自訂地圖與實體生成器
* **檔案位置**：`map_generator.py`
* 目前地圖採用隨機漫步算法（Random Walk）。您可以修改 `generate()` 函數，改為經典的 BSP 區塊分割演算法或迷宮生成演算法。
* 您可以在 `place_entities()` 中增加更多自訂的實體，例如陷阱、NPC 商人、甚至是 Boss 房間。

### 3. 新增怪物與平衡數值
* **檔案位置**：`config.py`
* 在 `MONSTER_TYPES` 清單中新增新的字典，設定自訂的名稱、HP、攻擊力與防禦力。
* 調整 `PLAYER_MAX_HP`、`PLAYER_ATK` 或 `PLAYER_DEF` 等常數，來微調遊戲的整體難易度。

## 🛠️ 開發與測試環境

### 依賴套件
在執行前，請確保安裝以下 Python 套件：
```bash
pip install flask google-genai
```

### 啟動遊戲
在終端機中，切換至專案根目錄並執行：
```bash
python main.py
```
伺服器啟動後會自動在瀏覽器中開啟 `http://127.0.0.1:5000`。
*(請確保已在環境變數中設定 `GEMINI_API_KEY`，否則遊戲將自動降級至本地預設文字模式)*

### 執行單元測試
本專案已附帶針對核心戰鬥、防禦機制與裝備數值的單元測試：
```bash
python test_game.py
```

## 🎮 操作方式

| 模式 | 鍵盤 | 滑鼠/觸控 |
|------|------|-----------|
| 探索 | W/A/S/D 或方向鍵 | 點擊虛擬方向鍵 |
| 戰鬥 | 1(攻擊) / 2(防禦) / 3(藥水) | 點擊戰鬥按鈕 |
| 事件 | A / B | 點擊選項按鈕 |
| 遊戲結束 | 任意鍵重新開始 | 點擊重新開始按鈕 |
