# 《從底層出發：精通 Linux 系統程式與並行控制實戰》

## 書籍簡介
本書旨在為具備 C 語言基礎的讀者，提供一份全面且深入的 Linux 系統程式設計指南。我們將從作業系統底層核心概念出發，結合大量實戰範例，帶領讀者徹底理解行程管理、檔案 I/O、信號處理、並行控制、行程間通訊與網路通訊的核心機制。本書拒絕空泛理論，強調「理論 -> 底層 syscall 剖析 -> 程式碼實作 -> 常見 Bug 盲點分析」的實戰導向學習模式，助讀者真正掌握系統程式設計的精髓。

## 目標讀者
*   希望深入理解作業系統底層運作原理的軟體工程師。
*   資訊科學相關科系，欲加強系統程式實作能力的學生。
*   對高效能、高併發系統設計感興趣的開發者。

## 寫作風格
專業、扎實、重實作且 `scannable`。每章均以「理論 -> 底層 syscall 剖析 -> 程式碼實作 -> 常見 Bug 盲點分析」的結構進行。

## 詳細目錄與寫作藍圖

### Chapter 1: 環境建置與系統程式基礎

*   **本章核心觀念（Core Concepts）**：
    *   系統程式設計概論：為什麼要學習系統程式？與應用程式的區別。
    *   Linux 開發環境建立：GCC 編譯器、Make 工具、GDB 除錯器、核心函式庫 (glibc)。
    *   系統呼叫 (System Call) 概念：使用者空間與核心空間、陷入指令 (trap instruction)、系統呼叫的執行流程。
    *   `strace` 與 `ltrace`：觀察程式的系統呼叫與函式庫呼叫。
    *   錯誤處理：`errno` 與 `perror`。
*   **圖解或思維導圖建議**：
    *   GCC 編譯鏈流程圖 (前處理、編譯、組合、連結)。
    *   使用者空間與核心空間切換示意圖。
    *   系統呼叫參數傳遞與返回值流程圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   編寫一個簡單的 C 語言 "Hello, World!"，並使用 `GCC`、`Make` 編譯。
    *   使用 `GDB` 除錯一個帶有簡單邏輯錯誤的 C 程式。
    *   透過 `strace` 觀察 `printf` 函式背後的 `write` 系統呼叫。
    *   實作一個使用 `perror` 處理錯誤的檔案開啟範例。

### Chapter 2: 檔案 I/O 與系統資源管理

*   **本章核心觀念（Core Concepts）**：
    *   檔案描述符 (File Descriptor, FD)：概念、標準 FD (0, 1, 2)。
    *   `open()`, `read()`, `write()`, `close()`, `lseek()`：核心檔案 I/O 系統呼叫。
    *   `stat()`, `fstat()`, `lstat()`：獲取檔案資訊。
    *   `dup()`, `dup2()`：複製檔案描述符。
    *   緩衝區 I/O vs. 無緩衝 I/O：效率與控制。
    *   檔案存取權限與檔案類型。
*   **圖解或思維導圖建議**：
    *   行程的檔案描述符表 (FD table) 結構示意圖。
    *   檔案 I/O 緩衝機制圖。
    *   `dup2` 改變 I/O 重新導向示意圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   實現一個簡單的 `cp` 命令 (檔案複製工具)，分別使用系統 I/O 和標準 I/O，並比較其效能。
    *   編寫程式使用 `dup2` 實現標準輸出重導向到檔案。
    *   設計一個程式，接收檔案路徑並顯示其類型、大小和權限。

### Chapter 3: 行程管理與控制

*   **本章核心觀念（Core Concepts）**：
    *   行程 (Process) 概念：程式與行程的區別、行程狀態、行程控制區 (PCB)。
    *   `fork()`：建立子行程、父子行程的記憶體空間與資源繼承。
    *   `exec` 系列函數：載入並執行新程式。
    *   `wait()`, `waitpid()`：等待子行程結束、防止殭屍行程。
    *   孤兒行程 (Orphan Process) 與殭屍行程 (Zombie Process)。
    *   行程樹 (Process Tree)。
    *   `getpid()`, `getppid()`：獲取行程 ID。
*   **圖解或思維導圖建議**：
    *   行程狀態轉換圖。
    *   `fork()` 後父子行程記憶體空間關係圖。
    *   `fork()`/`exec()` 後的行程樹結構圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   自製一個迷你 `Shell`，支援簡單的外部命令執行 (`ls`, `pwd`) 和背景執行 (`&`)。
    *   編寫程式演示孤兒行程和殭屍行程的產生與處理。
    *   實作一個行程管理器，可以列出所有子行程並終止特定子行程。

### Chapter 4: 信號處理

*   **本章核心觀念（Core Concepts）**：
    *   信號 (Signal) 概念：軟體中斷、同步與非同步信號。
    *   信號的產生、傳遞與處理：`kill()`, `alarm()`, `pause()`, `sleep()`。
    *   `signal()` 與 `sigaction()`：註冊信號處理函數。
    *   信號處理函數 (Signal Handler) 的設計：可重入性、非同步安全函式。
    *   信號阻塞與解除阻塞：`sigprocmask()`。
    *   處理常見信號：`SIGINT`, `SIGTERM`, `SIGCHLD`, `SIGSEGV`。
*   **圖解或思維導圖建議**：
    *   信號處理流程圖。
    *   信號掩碼 (Signal Mask) 示意圖。
    *   信號處理函數棧幀切換示意圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   實現一個可中斷的定時器，展示如何捕獲 `SIGINT` (Ctrl+C) 並安全退出。
    *   編寫程式演示 `SIGCHLD` 的捕獲，以非阻塞方式回收子行程資源。
    *   設計一個程式，使用 `alarm` 實現超時機制。

### Chapter 5: 執行緒與同步機制

*   **本章核心觀念（Core Concepts）**：
    *   執行緒 (Thread) 概念：輕量級行程、行程與執行緒的區別。
    *   `pthread` 庫：`pthread_create()`, `pthread_join()`, `pthread_exit()`, `pthread_self()`。
    *   執行緒間的資料共享與競爭條件。
    *   互斥鎖 (Mutex)：`pthread_mutex_init()`, `pthread_mutex_lock()`, `pthread_mutex_unlock()`。
    *   號誌量 (Semaphore)：`sem_init()`, `sem_wait()`, `sem_post()`。
    *   條件變數 (Condition Variable)：`pthread_cond_init()`, `pthread_cond_wait()`, `pthread_cond_signal()`, `pthread_cond_broadcast()`。
    *   讀寫鎖 (Read-Write Lock)：`pthread_rwlock_init()`。
    *   死結 (Deadlock)：產生條件與避免策略。
*   **圖解或思維導圖建議**：
    *   行程與執行緒資源共享模型圖。
    *   Mutex 鎖定與解鎖示意圖。
    *   Semaphore 資源計數示意圖。
    *   條件變數的等待與通知機制圖。
    *   死結環路圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   實現一個多執行緒銀行系統，包含存款、取款操作，並使用 `Mutex` 確保帳戶資料一致性。
    *   實作經典的「生產者-消費者」模型，使用 `Mutex` 和 `Condition Variable` 協調。
    *   編寫一個簡單的多執行緒計算任務，比較有鎖與無鎖的性能差異。

### Chapter 6: 行程間通訊 (IPC)

*   **本章核心觀念（Core Concepts）**：
    *   行程間通訊概論：為何需要 IPC？多種 IPC 機制選擇。
    *   無名管道 (Pipe)：父子行程間的單向通訊。
    *   命名管道 (FIFO)：任意行程間的通訊。
    *   共享記憶體 (Shared Memory)：最快的 IPC 方式、`shmget()`, `shmat()`, `shmdt()`, `shmctl()`。
    *   訊息佇列 (Message Queue)：`msgget()`, `msgsnd()`, `msgrcv()`。
    *   System V IPC vs. POSIX IPC。
    *   記憶體映射 (Memory Mapping, `mmap()`)：將檔案或匿名記憶體區域映射到行程地址空間。
*   **圖解或思維導圖建議**：
    *   管道通訊示意圖。
    *   共享記憶體區塊與行程地址空間映射圖。
    *   訊息佇列結構圖。
    *   `mmap` 檔案映射示意圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   使用無名管道實現父子行程間的文字傳輸。
    *   使用命名管道 (FIFO) 實現兩個獨立行程的單向通訊。
    *   透過共享記憶體和號誌量實現一個多行程共享計數器。
    *   利用 `mmap` 實現一個大檔案的快速複製。

### Chapter 7: 網路通訊 (Socket)

*   **本章核心觀念（Core Concepts）**：
    *   網路程式設計基礎：OSI 模型簡介、TCP/IP 協議棧。
    *   Socket 概念：端點、地址、埠。
    *   Socket 類型：`SOCK_STREAM` (TCP) 與 `SOCK_DGRAM` (UDP)。
    *   TCP Server/Client 程式設計流程：`socket()`, `bind()`, `listen()`, `accept()`, `connect()`, `send()`, `recv()`, `close()`。
    *   位元組順序 (Byte Order) 轉換：`htons()`, `ntohs()` 等。
    *   位址轉換：`inet_aton()`, `inet_ntoa()`。
    *   I/O 多工 (I/O Multiplexing)：`select()`, `poll()`, `epoll()`。
*   **圖解或思維導圖建議**：
    *   TCP 三次握手與四次揮手圖。
    *   Socket 通訊流程圖 (Server/Client)。
    *   `select`/`poll`/`epoll` 監聽多個 FD 示意圖。
*   **實戰專案/範例程式（Hands-on Lab）**：
    *   實現一個簡單的 TCP 客戶端/伺服器聊天室，支持多客戶端連接。
    *   編寫一個基於 UDP 的時間同步服務。
    *   使用 `select()` 或 `epoll()` 實現一個高效能的單行程多客戶端伺服器 (例如，一個迷你 HTTP 伺服器)。
